🌱 EcoTrack – Environmental Activity Tracking System

About the Project

EcoTrack is a web-based environmental activity tracking system developed to encourage people to adopt eco-friendly habits and contribute towards environmental sustainability.

The application allows users to record eco-friendly activities, track their daily carbon footprint, explore recycling practices, and monitor their environmental progress. It aims to create environmental awareness and motivate users to make sustainable choices in their everyday lives.

Features

- Carbon Tracker – Estimates carbon footprint based on travel distance, electricity usage, and daily meals.
- Eco Activities – Allows users to select eco-friendly activities, enter quantities, and save their contributions.
- Recycling – Promotes recycling and responsible waste management.
- Progress Tracking – Helps users monitor their environmental activities and progress.
- Rewards – Encourages sustainable habits through a reward-based system.

How to Run the Project

1. Install Java JDK and Eclipse IDE.
2. Configure Apache Tomcat in Eclipse.
3. Configure MySQL database according to the project requirements.
4. Import the EcoTrack project into Eclipse.
5. Configure the database connection.
6. Run the project on Apache Tomcat.
7. Open the application in your web browser.
